# BELIER 분석실 설치 (팀 내부용)

맥 **터미널**을 열고(Spotlight에서 "터미널"), 아래 한 줄을 붙여넣고 Enter:

```
curl -fsSL https://raw.githubusercontent.com/belier-bong/belier-room/main/install.sh | zsh
```

- 접속 키는 이 저장소에 없습니다. 봉주에게 AirDrop 으로 받은 `접속키.txt` 가 다운로드 폴더에 있으면 자동으로 찾고, 없으면 붙여넣으라고 묻습니다.
- 끝나면 Claude 앱 › Code 탭 › 새 세션에서 폴더 `데스크탑 › 프로젝트 › belier-분석실` 을 고르고 한국어로 물어보세요.
- 업데이트도 같은 한 줄입니다(내가 만든 보고서·쿼리는 그대로 남습니다).
